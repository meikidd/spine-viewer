# 首版人工验收清单

## 当前执行记录

- 2026-09-09：桌面 Chrome 已通过官方 Spine 3.8 JSON、`.skel`、动画切换、
  Debug 和事件标记联动流程，控制台无错误。
- Edge 与 Safari 当前环境未安装，发布前仍需按下列清单人工验收。

## 准备

1. 运行 `npm install && npm run dev`。
2. 分别在最新版桌面 Chrome、Edge 和 Safari 打开本地地址。
3. 准备 `tests/fixtures/json` 和 `tests/fixtures/skel` 中的资源。

## 资源加载

- 分别选择 JSON 和 `.skel` 目录中的三个文件，确认动画正常显示。
- 缺少纹理、加入无关文件或选择错误版本，确认显示文件名和修复建议。
- 加载合法资源后再选择无效资源，确认原预览仍然保留。
- 快速连续选择两套资源，确认最终显示最后一次选择。

## 播放与视图

- 切换动画，确认从 `0s` 开始且保留原播放状态。
- 切换皮肤，确认动画、时间和播放状态不变。
- 拖动时间轴，确认拖动时实时更新、松开后保持暂停。
- 验证循环开关和五档速度；关闭循环后应停在末尾。
- 切换 PMA，确认资源重新加载且当前动画、时间和视图保持不变。
- 验证滚轮缩放、拖动画布平移和重置视图。

## 事件与 Debug

- 在包含事件的动画中，确认事件按时间排序并显示时间轴标记。
- 分别点击列表项和时间轴标记，确认两侧高亮、暂停并跳到准确时间。
- 展开事件，确认 `int`、`float`、`string` 和存在的音频元数据显示正确。
- 开启 Debug，确认默认显示骨骼和边界框。
- 逐项切换区域、网格、路径、裁剪、点和外壳。

## React API 与生命周期

- 使用 `files` 加载资源，并用 `showUploader={false}` 隐藏内置上传。
- 验证公开回调，以及 Ref 的播放、暂停、定位、动画和皮肤命令。
- 卸载并重新挂载组件，确认没有残留渲染循环、监听器或 WebGL 资源。
- 模拟 WebGL 上下文丢失，确认显示错误并暂停播放。

## 发布检查

```bash
npm run typecheck
npm test
npm run build
npm pack --dry-run
```

确认 npm 包包含 JavaScript、CSS、TypeScript 声明和
`SPINE-RUNTIMES-LICENSE`，且不包含 demo 或测试资源。
